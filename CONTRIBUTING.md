# Community Guidelines

Welcome to the `nosaurus-go` community! While this project is currently maintained by a single contributor, all respectful feedback, contributions, and collaboration are welcome.

## 🤝 Respect and Collaboration

- Be kind and constructive.
- Assume positive intent from others.
- Offer feedback that is actionable and specific.

## 🛠️ Contributions

Want to help out? Great!

- Fork the repo, create a feature branch, and submit a pull request (PR).
- Make sure your code is clean, documented, and passes tests.
- Open an issue before making large changes.

## 🧠 Discussions

- Use [GitHub Issues](../../issues) for bug reports, feature requests, or questions.
- Keep discussions focused and relevant.
- Avoid off-topic or spammy content.

## 🔒 Security

If you discover a vulnerability, **please do not file a public issue**. Follow the [SECURITY.md](./SECURITY.md) process to report it privately.

## 🙌 Recognition

All contributors are appreciated. Your help—whether reporting bugs, suggesting features, or fixing typos—is valuable.

---

Thank you for being a part of the project!
